# AI智能体开发教学项目

这是一个基于Python的AI智能体开发教学项目，旨在帮助学习者掌握AI智能体开发的核心技能。

## 项目结构

```
.
├── .env.example              # 环境变量配置模板
├── .env                      # 环境变量配置文件（需从模板复制）
├── .gitignore                # Git忽略文件
├── venv/                     # Python虚拟环境
├── practice01/               # 练习1：LLM API调用
│   └── llm_api_test.py       # LLM API调用测试脚本
├── practice02/               # 练习2：终端聊天与工具调用
│   ├── terminal_chat.py     # 终端聊天脚本（流式输出）
│   ├── tools.py             # 文件操作工具函数
│   └── tool_calling.py      # 工具调用主程序
├── practice03/               # 练习3：上下文压缩与历史记录
│   ├── chat_with_compression.py  # 带上下文压缩的聊天程序
│   └── chat_with_history.py      # 带历史记录提取与搜索的聊天程序
├── practice04/               # 练习4：AnythingLLM集成
│   └── chat_client.py           # 带文档仓库查询的聊天程序
├── practice05/               # 练习5：技能系统集成
│   └── tool_client.py           # 带技能加载和调用的聊天程序
├── .agents/                  # 技能目录
│   └── skills/               # 技能存放目录
│       └── notice/           # 通知技能
│           └── SKILL.md      # 技能定义文件
└── README.md                 # 项目说明文档
```

## 环境配置

### 1. 激活虚拟环境

```bash
# Windows
venv\Scripts\activate

# macOS/Linux
source venv/bin/activate
```

### 2. 配置LLM服务

复制环境变量模板并配置：

```bash
# 复制模板
copy env.example .env

# 编辑.env文件，填入正确的LLM配置
# - LLM_BASE_URL: LLM服务地址
# - LLM_MODEL: 模型名称
# - LLM_API_KEY: API密钥
```

### practice05/tool_client.py

**功能用途：**
- 实现技能系统的动态加载和调用
- 自动读取 `.agents/skills` 目录下的所有技能
- 解析技能的 YAML front matter（name、description）
- 将技能列表以 JSON 格式发送给 LLM
- 支持加载技能正文内容供 LLM 执行

**教学目标：**
1. 学习技能系统的设计与实现
2. 掌握 YAML front matter 解析
3. 理解技能动态加载机制
4. 学习技能调用的系统提示词设计
5. 掌握技能文件结构规范

**核心功能：**

1. **技能列表读取** (`list_available_skills`)
   - 遍历 `.agents/skills` 目录下的一级子目录
   - 读取每个子目录中的 `SKILL.md` 文件
   - 解析 YAML front matter，提取 `name` 和 `description`
   - 返回技能列表 JSON

2. **技能内容加载** (`load_skill_content`)
   - 根据技能名称加载对应的 `SKILL.md` 文件
   - 提取 YAML front matter 之后的正文内容
   - 返回技能执行指令

3. **系统提示词生成** (`get_skills_system_prompt`)
   - 生成包含技能列表的系统提示词
   - 定义技能调用规则和格式
   - 将技能列表以 JSON 格式传递给 LLM

**技能文件结构：**

```markdown
---
name: notice
description: 撰写通知、修改通知、润色通知
---

# 通知撰写技能

## 使用规则
1. 通知不能以"通知"二字开头，必须冠以"XX部"的前缀
2. 例如："采购部通知"、"宣传部通知"等
3. 如果用户没有告知所在部门，就使用"XX部"代替
```

**目录结构：**

```
.agents/
└── skills/
    └── notice/           # 技能目录（以技能名称命名）
        └── SKILL.md      # 技能定义文件
```

**运行方式：**

```bash
python practice05/tool_client.py
```

**测试示例：**

```

[
  {
    "name": "notice",
    "description": "撰写通知、修改通知、润色通知"
  }
]

# 通知撰写技能

## 使用规则

## 通知格式模板
[部门名称]通知

尊敬的各位同事：

[通知内容]

特此通知。

[部门名称]
[日期]

Testing get_skills_system_prompt:

技能调用规则：

用 [function name=load_skill_content][parameter name=skill_name]技能名称[/parameter][/function] 格式调用技能
```
